# Laboratorio interactivo de Fundamentos de Electrónica

Guía de estudio para CORHUILA · Ingeniería de Sistemas.

HTML, CSS y JavaScript puros. Fórmulas con KaTeX. Sin React ni compilador.

## Cómo abrirla

No abras `index.html` con doble clic: los módulos se cargan con `fetch` y el navegador lo bloquea en `file://`.

1. En VS Code instala la extensión **Live Server**.
2. Clic derecho en `index.html` → **Open with Live Server**.

## Módulos

| # | Tema | Herramienta |
|---|------|-------------|
| 1 | Carga eléctrica | Simulador de cargas y constructor de iones |
| 2 | Ley de Coulomb | Calculadora con conversión de unidades |
| 3 | Resistencias | Código de colores, inverso, serie/paralelo |
| 4 | Ley de Ohm | Calculadora V / I / R |
| 5 | Sistemas numéricos | Conversor entre bases 2, 8, 10 y 16 |
| 6 | Operaciones binarias | Suma, resta y multiplicación paso a paso |
| 7 | Puertas lógicas | Simulador AND, OR, NOT, NAND, NOR, XOR, XNOR |

## Publicar

Sube la carpeta a GitHub y activa GitHub Pages en la rama principal (carpeta `/`).
