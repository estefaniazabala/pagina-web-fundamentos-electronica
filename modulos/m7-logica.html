Puertas lógicas

AND, OR, NOT, NAND, NOR, XOR y XNOR: símbolo, expresión y tabla de verdad.

Qué es una puerta lógica

Definición Una puerta lógica es un circuito digital que combina señales de 0 (falso, apagado, bajo) y 1 (verdadero, encendido, alto) según una regla.

Las expresiones se escriben con A, B, C… El punto (·) o nada significa AND; + significa OR; la barra o ¬ significa NOT.

Expresión con tres variables

Ejemplo: \(Y = A \cdot B + C\). Primero se hace el AND de A y B, y el resultado se combina en OR con C.

Si A=1, B=0, C=1
1
A·B = 1·0 = 0
2
0 + C = 0 + 1 = 1
Y = 1
